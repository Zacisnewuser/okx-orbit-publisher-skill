# 2.0.1 发布前检查

检查日期：2026-09-08。范围：本仓库通用 Skill、状态脚本、测试、说明及构建工具，不包含任何真实账号运行数据。

## 结论

可作为 MIT 开源的早期社区预览发布；不是已完成所有 Agent/浏览器实测的无人值守产品。

## 已检查

- 在 macOS / Python 3.14.2 运行 24 项离线回归测试，全部通过（18 项状态测试、6 项脱敏扫描回归）。
- 覆盖默认暂停、配置变更撤销批准、重复内容、并发执行/初始化、额度冷却、过期任务、未知提交、保护名单、观察记录、备份恢复及失败回滚。
- 修复过期草稿阻挡重新入队；增加未尝试草稿取消流程；保留已发送与未知提交历史。
- 初始化的结构、默认配置和版本在同一事务提交；恢复副本在发布到目标目录前强制暂停。
- 配置拒绝非有限数字、非法时间与不完整调度登记；URL 拒绝控制字符及歧义路径。
- 发布源使用独立目录，人工核对文件清单并扫描个人路径、账号标识、凭据格式和运行数据。
- 发布构建采用明确白名单；仅含 Skill、通用说明、标准库脚本和 MIT 许可证，不包含数据库、Cookie、个人配置、运营队列或 Git 历史。
- 提供贡献指南、安全报告指引、Issue/PR 模板及固定依赖提交的只读权限 CI 配置。
- 脱敏复核同时检查当前源码、拟发布提交的全部祖先与历史文件，以及 ZIP 正文、文件名和注释；默认不回显敏感匹配值。
- 作者与提交者身份必须在上传前显式指定为公开用户名和 GitHub noreply 邮箱，禁止依赖连接器默认身份。上传后重新拉取并检查远端历史。

## 验证边界与后续工作

- GitHub Actions 矩阵配置不等于已通过云端测试；上传后须查看实际运行结果。
- 未执行真实星球发布、评论、关注或登录验证。每个用户的浏览器与调度适配必须先只读验收、再模拟运行。
- 本地状态工具不是恶意 Agent 的安全沙箱，也不能证明页面证据、语义质量或用户授权真实性。
- 候选发现断点、完整粉丝快照、调度登记验收等仍由宿主 Agent 按协议保存和核验，未实现独立后台服务。
- 敏感内容扫描是启发式检查，不是不存在任何隐私风险的保证；后续每个 PR 和发行包仍需人工检查。
- Git 历史重写不保证清除服务器缓存或其他人的副本；已经暴露的旧对象需按 GitHub 的敏感数据清理流程另行处理，未确认清除前不要重新开放存在风险的仓库。

复现命令见 [README](../README.md)。社区优先贡献不同 Agent/浏览器的适配验收案例、失败恢复样例，以及状态库升级迁移测试。
