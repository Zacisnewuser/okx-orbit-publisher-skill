# 外部能力与 Agent 适配

## 依赖分层

| 用户要做什么 | 需要什么 | 缺失时仍可做什么 |
|---|---|---|
| 聊天写稿/改风格 | 宿主文本能力 | 用户提供固定文案 |
| 保存配置、队列、去重 | 本地文件、Python 3.9+ 标准库 | 临时聊天草稿，明确无法持久化 |
| 发布、评论、点赞、在线指标 | 可控制用户已登录 Chrome 的外部工具 | 写稿、查看本地历史 |
| 定时运营 | 能调用本 Skill 和共享状态的调度工具 | 用户聊天触发 |
| 关系管理 | 浏览器关系读取和完整性验证 | 保持关闭，提供人工候选分析 |

本包不包含第三方浏览器 Skill、MCP 服务、浏览器扩展、模型网关或调度器。也不默认安装后台服务。

## 浏览器选择与验收

先检查宿主已提供工具并阅读其实际说明。可考虑宿主原生浏览器工具、Playwright 类工具或 agent-browser 类 Skill，但这些只是候选类别，不能仅凭工具名称保证兼容。若工具只能启动无登录浏览器，不能立即用它正式提交。

缺依赖时向用户说明用途，查询对应工具的当前官方安装文档，给最少必要安装步骤；由用户选择安装。不要捆绑其他 Skill，不猜安装命令，不为本 Skill 修改全局浏览器安全配置。Python 缺失同样按外部运行环境引导，不假定所有 macOS 自带 Python。

用户配置后只读验收：

- 可读取用户手动登录的可见 Chrome 标签页；账号公开 ID 与已配置一致。
- 可读取 URL、原帖正文和稳定目标 ID；可以定位唯一编辑器/按钮，并读取操作后的公开结果。
- 可检测登录、人脸/验证码、越界 URL、页面异常；不会自动重试写入。
- 仅在星球主页/详情的真实已核验路径建立范围白名单，使用精确域名及路径边界；不能将整个 OKX 域名或 `/` 放行。

不要以测试为由发帖/点赞。记录浏览器工具名、验收时间和能力；每次写入仍需重新在线检查，历史验收不是永久登录证明。

## 调度选择与验收

优先使用宿主 Agent 已有调度。Codex 可使用其自动化工具；Hermes/OpenClaw 用当前环境实际提供且有文档的调度能力。不要求一定叫 cron，不生成未经验证的命令。用户没有调度时建议兼容工具，保留手动模式。

只在用户要求定时运行时配置，登记调度提供方、任务 ID、功能、时间、时区、状态、最近验收和计划下次运行。每个任务调用同一 Skill/状态目录；开头读暂停状态，只运行一个有界工作单元。规则放在 Skill 与配置，定时提示词只包含功能和状态定位，不复制全套策略。

设置完读取实际调度确认时间；优先空跑一次，确保可加载本地状态且 dry-run 无公开提交。用户修改时间时更新既有任务，不创建重复项。暂停时逐项暂停登记任务；工具失联则报告调度尚未确认停止，保留本地暂停。旧任务若未接入本地门禁，必须先停用，不能假称被新暂停状态控制。

本 Skill 不自带运行循环。只有调度宿主确实支持时才承诺 Agent 关闭后运行；电脑休眠、退出会话、工具离线可能影响执行，应在用户选择定时时用一句话解释实际条件。

## 换 Agent

新 Agent 读取同一个状态目录，先展示现有模式、暂停原因和待处理任务，再验收自己的工具。保持原任务 ID 和去重历史，不重复初始化或复制数据库。已有 `executing/unknown` 阻止新的公开操作。跨机器迁移须走备份恢复，不能让两份副本同时运营同一账号。

原生任务的自动归档、通知、微信发送都属于宿主可选功能，不是核心依赖。不要自动归档主任务或擅自发消息给第三方。
